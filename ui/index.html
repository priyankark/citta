Shell, scripts and code
Allow the full-tool agent profile below and sign in to its harness on the receiving device. It uses that device’s files, installed tools and skills.
Desktop and browser interaction
Keep the receiving desktop unlocked. On a Mac, open System Settings → Privacy & Security. Allow Accessibility for input and Screen & System Audio Recording for screenshots when your task needs them. Grant Automation for the specific app if macOS requests it. These grants are separate from Citta’s execution mode.
Email and other signed-in apps
Sign in to the intended account on the receiving device and check the sender and recipient before sending. A connection or completed agent run alone does not confirm that a message was sent.

After changing macOS grants, restart Citta when its jobs are idle. Ask a delegated worker to test the action. Desktop and account access are not verified by this panel.
