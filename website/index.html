A FEW GOOD QUESTIONS

Before you
connect.

Which agents can use Citta?+

Citta exposes MCP tools and command adapters. Setup configures the documented Codex path. Other harnesses need compatible MCP configuration and a receiving-side adapter. See the adapters guide.

Does everything run locally?+

Citta runs on your devices without a required cloud task coordinator. Your agent harness and its tools may still use cloud services. Local models run on the device that hosts them.

What access do other agents get?+

The receiving device’s Citta policy, agent harness and OS permissions control access. Full-tool agents can run commands and edit files as that account. Use your own trusted devices; this is not a sandbox for untrusted workloads.

Is Citta ready for my workflow?+

0.1.0 is an early release with tested cross-device coding and model tasks. Desktop permission continuity, whole-device sleep and network recovery, and longer reliability testing remain open. Read the verified scope.
